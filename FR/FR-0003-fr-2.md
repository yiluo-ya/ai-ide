# 一、终局形态：它到底是个什么东西

先把定位从「一个读代码的网页」往上提一层：

> **它是人类理解代码的最后一公里。**
> 输入一份陌生代码（尤其是 AI 生成的），输出「我懂了」——
> 不是让代码显示出来，而是让人**走得进、问得出、带得走、说得清**。

用一句话概括当前状态与终局的差距：

| 现在 | 终局 |
|---|---|
| 以**文件**为中心（我点开一个文件） | 以**问题**为中心（我要搞懂「请求怎么进来的」） |
| 无状态的**查看器**（关掉就忘） | 有记忆的**工作台**（看到哪、标了什么、想过什么） |
| 人**自己找**（F12 一次次按） | 工具**带人找**（给我路径、给我解释、给我全景） |
| 与 agent **单向、断开** | 与 agent **共享同一份上下文** |

# 二、全景图：六个角色 + 一个底座

终局形态不是一堆功能，是**六个角色**同时在场。当前产品只把「导航员」做了一半。

```
                     ┌──────────────────────────────────────────┐
                     │             人  （读懂代码）               │
                     └───┬────────┬────────┬────────┬────────┬───┘
                         │        │        │        │        │
              ┌──────────▼─┐ ┌────▼─────┐ ┌▼───────┐ ┌▼─────┐ ┌▼────────┐
              │ ① 地图 Map │ │② 透镜 Lens│ │③ 导航  │ │④ 向导│ │⑤ 信使   │
              │ 这项目长啥样│ │这是什么   │ │它在哪  │ │先看啥│ │带得走吗 │
              │ 入口/热点  │ │签名/类型  │ │谁用它  │ │怎么读│ │给agent? │
              │ 依赖/分层  │ │来源/文档  │ │调用链  │ │讲一遍│ │给同事?  │
              └────────────┘ └──────────┘ └────────┘ └──────┘ └─────────┘
                         │        │        │        │        │
                     ┌───▼────────▼────────▼────────▼────────▼───┐
                     │  ⑥ 底座 Platform：索引引擎 / 交付 / 性能   │
                     │     隐私 / 质量 / 扩展性 / 可观测          │
                     └────────────────────────────────────────────┘
```

**关键判断**：现在这个产品 = ③导航（做了约一半）+ ⑥底座（做了约三分之一），
①地图 ④向导 ⑤信使 基本是空的，②透镜 只有语法色和语义色。

# 四、边界：明确**不做**什么（产品经理必须给）

| 不做 | 理由 |
|---|---|
| 编辑、运行、编译、调试、重构 | 只读定位是差异化，做了就变成半个 IDE，永远打不过 VS Code |
| 完整 git 客户端 | 只做「读得懂」相关的（diff/历史），不做提交/合并 |
| 多人协作 / 账号 / 云端托管 | 本机工具，隐私即卖点 |
| 自研类型推断引擎 | 该能力属于 LSP，若要就「接现成的」，不自己造 |
| 依赖包内部符号分析 | 边界清晰，外部一律标注不跳转 |

# 六、需要你现在拍板的四个**形态级**问题

这几个决定不先定，「怎么做」会反复推倒：

1. **它是「工具」还是「助手」？** ——要不要引入 LLM（解释/摘要/阅读路径/语义搜索）。这一步决定 V5 存不存在，也决定架构要不要留 LLM 侧。
2. **它是「单机应用」还是「宿主面板」？** ——你说的 share，是发给同事一个 exe（单机自主），还是主要嵌在 xchen 里（宿主托管）？两者在交付、生命周期、UI 密度上完全不同。
3. **它的用户只有你自己，还是包括同事/团队？** ——决定要不要首次引导、错误友好、多目录/工作区。
4. **范围是否守住「只读阅读器」？** ——即「四、边界」你是否认同；认同我就按此设计，不认同（比如你想要轻量编辑/批注写回）现在就要说。
