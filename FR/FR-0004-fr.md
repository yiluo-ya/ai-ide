# FR-0004 · 05 信使 Share：带得走、接得上

> 对应 `docs/05-share.md`（信使 Share）的落地需求。前置：`FR/FR-0002-fr.md`（只读定位）、`FR/FR-0003-fr-2.md`（六主题盘点）。
> 一句话：**把我读到的那个位置、那段代码、那份理解带走并交出去 —— 交给人，也交给 agent。**

## 一、为什么做（用户视角）

只读阅读器最容易死在这里：理解只发生在屏幕上。读通了一个项目，关掉标签页一切归零；
要跟同事说「就是 `auth.py` 第 42 行那个地方」得手动抄路径和行号；想让 agent 别再用 grep 猜代码，
却没有通道把「我已经建好的索引」借给它。

三句原话：

1. 「我读到的这个点，怎么一句话发出去」——同事、未来的我、或 agent，拿到就能落到同一行。
2. 「这段代码我要贴到聊天窗里讨论」——贴出去的片段必须自带出处（哪个文件、哪几行）。
3. 「我读懂了，怎么把这份理解交出去」——不是交源码，而是交一份「按这个顺序看这几处」；
   同时 agent 想查代码时，应该能查索引，而不是 grep。

## 四、边界（本轮明确不做）

- 不做编辑 / 运行 / 编译 / 调试 / 重构：信使只搬「位置与文本」，不搬「改动」。
- 不做云端托管、账号、权限（不提供 SaaS 形态的分享链接）。
- 不把被读代码复制到临时目录；不打包源码（S5b 留后续）。
- 不做代码片段的执行或沙箱：导出物是给人读的。
- 批注不写回源码文件；agent 工具只读（不改文件、不执行命令、不跑测试）。
- 不做整仓公开分享页。

## 五、实现路径（关键取舍）

1. **纯函数与副作用分离**：`share.ts` / `report.ts` / `annotations.ts` 只做格式化与存储，方便单测；
   剪贴板 / 下载 / canvas 这类浏览器能力单独放在 `report.ts` 尾部与 `snapshot.ts`。
2. **顶栏一个收口**：新增能力不再往导航栏堆按钮，统一进「分享 ▾」下拉（ShareMenu）。
3. **选区感知靠 Monaco action**：`wcr.copySnippet`（`precondition: editorHasSelection`）与 `wcr.copySymbol`
   走编辑器右键菜单，快捷键留给已有约定。
4. **回发不经 React state**：光标是高频事件，`reportCaret()` 直接调用（`bridge.ts`），避免每次移动都触发重渲染。
5. **清理语义可核对**：dispose 的每一步都在响应里报（`stoppedWatcher` / `closedStreams` / `releasedIndex` / `kept`），
   另有 `/resources` 让宿主自证；注册表条目保留，避免宿主每次收起面板都要重新注册。
6. **SSE 能被立即关闭**：把 15 秒 ping 周期切成 500ms 分片等待，dispose 最多 0.5 秒就能断开连接。
